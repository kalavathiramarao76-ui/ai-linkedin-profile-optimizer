# AI‑Powered LinkedIn Profile Optimizer

A minimal Next.js app that lets users paste their LinkedIn profile text, sends it to OpenAI's GPT‑4o‑mini for rewriting, and displays the optimized result.

## Features
- Simple textarea input
- Server‑side OpenAI call (via API route or directly in component for demo)
- Real‑time result display
- Ready for Vercel deployment

## Getting Started
1. Install dependencies: `npm install`
2. Set `OPENAI_API_KEY` in Vercel environment variables.
3. Run locally: `npm run dev`
4. Deploy to Vercel: `vercel` (or push to GitHub and enable Vercel auto‑deploy).
